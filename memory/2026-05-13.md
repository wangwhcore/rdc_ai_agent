## 低代码平台前端 JSON 描述文件分析

分析了 `e:\2026demo\rdc-develop\front` 工作区，这是一个低代码开发平台生成的前端 JSON 描述文件集合，用于运行期由引擎渲染为 React 页面。

### 项目基本信息
- 应用名：供应商管理中心（smc）
- 项目 GID：PJ181A490E5D4001 / App GID：1766F6ACFAB00B
- 运行时版本：front_web / neusoft_web
- 分支：master

### 文件结构
- **MdFrontLayout/**（401个）：页面/弹窗布局描述文件，每个文件为一个前端 Page 的完整 JSON
- **MdFunction/**（44个）：功能菜单/模块元数据，描述功能树结构（父子 parentGid 关系，virtual 标记虚拟节点）
- **app.properties / branch.properties / project.properties**：应用级元数据

### Layout JSON 核心结构
`value` 字段（JSON 字符串）包含：
- `desktop / pad / phone`：多端适配，pad/phone 通常引用 desktop
- `layoutInfo`：页面类型（view/list 等）、layout 模板名、包含的容器 IDs
- `layoutList`：容器集合，每个容器由 rows → cols → components 三层嵌套构成
- `components`：组件 id→定义 Map，含 type、property、subscribes
- `subscribes`：页面级事件订阅列表（pubsub 模型）
- `flows`：流程配置
- `defaultDataSource`：默认数据源

### 组件类型（已识别）
ButtonHook、SpanHook、TextHook、TextAreaHook、FindbackHook、ColumnHook、CardHook、UploadHook、NeuTag、NeuAnchor、ExceptionMessage、BtnOperationDetails、BtnAuditLog（自定义组件）

### 事件通信机制
- **pubsub 发布-订阅**：`pubsub.publish(event, payload)` 跨组件通信
- **事件命名规范**：`{componentId}.{action}` 如 `4a843889ebbf4d8e9927d55fe9b63878-cancelBtn.click`
- **特殊事件**：`@@form.init`、`@@form.change`、`@@navigator.push`、`@@message.success`

### 数据请求
- `resolveFetch()` 异步获取表单数据
- `behaviors: [{type: 'request', dataSource: {...}}]` 内嵌 API 调用
- `dataSource` 含 method/serverName/url/bodyExpression/returnDataExpression

### 国际化
- 使用 `$${key}` 占位符，如 `$${button.ok}`、`$${label.baseInfo}`

### Function JSON 结构
- 功能模块树（parentGid 构成树形结构）
- `virtual:1` 为虚拟节点（仅作分组）
- `frontId` 关联对应的 Layout 文件
- `enabled`/`state` 控制菜单可见性
